# Землетрясение 2023 — процедурный 3D-фильм на JavaScript

Документальный ролик (~16 минут, 16:9, 1920×1080, 30 fps) по сценарию `assets/scenario.json`
с озвучкой `assets/voice.mp3`. Вся картинка — процедурная 3D/2D-графика на **three.js**,
весь звук — синтез на **Web Audio API**. Экспорт — покадрово через **Puppeteer** + **ffmpeg**.

## Быстрый старт

```bash
npm install                 # three.js, esbuild, puppeteer (скачает Chrome)
node tools/serve.js         # предпросмотр: http://localhost:8080/
```

В предпросмотре картинка стартует сама; звук браузер включит после первого клика/клавиши.
Клавиши: `Space` — пауза, `←/→` — ±5 с, `Shift+←/→` — ±30 с, `M` — выкл. эффекты.
`http://localhost:8080/?t=480` — начать с 480-й секунды (сам момент землетрясения).

## Рендер видео

Нужен **ffmpeg** в `PATH` (или `npm i ffmpeg-static`). Желательно — видеокарта.

```bash
node render.js                          # весь фильм → out/earthquake_2023.mp4
node render.js --workers 3              # 3 параллельных браузера (быстрее на хорошей GPU)
node render.js --from 470 --to 540      # только кусок (проверить сцену)
node render.js --scale 0.5              # черновик в половинном разрешении
node render.js --gl swiftshader         # если GPU нет (очень медленно)
```

Рендер **возобновляемый**: видео пишется сегментами по 30 с в `out/work/`; если прервать и
запустить снова — готовые сегменты пропускаются. Параметры: `--fps 30`, `--crf 17`,
`--preset medium`, `--quality 95` (JPEG кадров), `--sfx-volume 0.9`, `--voice-volume 1.0`,
`--chrome <путь к chrome>`, `--headful`, `--no-audio`, `--audio-only` (пересобрать только звук),
`--loudness -16` (целевая громкость, LUFS), `--duck on|off` (приглушение эффектов под голосом).

Сколько ждать: в фильме ≈ 28 900 кадров. На видеокарте один кадр 1080p занимает примерно
0.1–0.4 с (зависит от GPU), то есть 1–3 часа на воркер; `--workers 2..4` делит время.
Без GPU (`--gl swiftshader`) — в разы медленнее, для этого случая есть `--scale 0.5`.
Перед полным рендером удобно проверить кусок: `node render.js --from 480 --to 500`.

Что делает `render.js`:
1. Поднимает локальный сервер и открывает `index.html?render=1` в headless Chrome.
2. Для каждого кадра вызывает `window.seekTo(ms)` — кадр — это чистая функция времени,
   поэтому кадры можно рендерить в любом порядке и в нескольких браузерах параллельно.
3. Офлайн-рендерит звуковую дорожку эффектов (`OfflineAudioContext`) и забирает её из страницы.
4. Нарезает озвучку и вставляет паузы (см. ниже), сводит с эффектами (`amix` + лимитер),
   склеивает сегменты и мультиплексирует в MP4 (H.264 + AAC 256k).

## Как устроена синхронизация с озвучкой

* `tools/prepare-data.js` превращает JSON (пословные тайминги Whisper) в `src/data/words.js`.
* План сцен (`src/shots/act*.js`) пишется привязкой к фразам: `S(T('the rupture races'), (c) => …)` —
  `T()` находит фразу в таймингах, поэтому каждая склейка происходит ровно на нужном слове.
* В `src/timing.js` → `GAP_SPECS` заданы 4 вставные паузы в озвучке (4 + 3 + 3 + 2 с) для эпичных
  моментов: сам разрыв в 04:17, поле ядерных грибов, город в облаке пыли и «7.5». Видео и звук
  сдвигаются автоматически; итоговая длительность ≈ 964.75 с.

## Структура

```
index.html            страница фильма (1920×1080, без UI)
dist/app.js           собранный бандл (npm run build)
render.js             экспорт видео через Puppeteer + ffmpeg
src/main.js           старт, seekTo(), предпросмотр с синхронизацией озвучки
src/director.js       таймлайн, камера, переходы (whip/flash/dip), рендер кадра
src/engine/           HDR-пайплайн (DOF, bloom, ACES, грейдинг, зерно), частицы, небо, текстуры
src/assets/           сцены: globe, regionmap, geoblock, city, syria, interior, macro, nukes, lab, istanbul, plates
src/overlay/          2D-слой: тайм-карты «1 YEAR BEFORE», инфографика, 2.5D-подписи
src/shots/act*.js     покадровый план (309 планов) + звуковые метки
src/audio/sfx.js      синтез эффектов, атмосфер и эмбиент-музыки на Web Audio
assets/               сценарий, озвучка, шрифты
```
